# Customer Shopping EDA & SQL Analysis

## 📌 Project Overview
This project performs Exploratory Data Analysis (EDA) and SQL-based analysis on a customer shopping trends dataset to uncover patterns and insights.

## 🎯 Objective
To analyze customer behavior, spending patterns, and category performance using Python, SQL, and data visualization.

## 📊 Dataset
- Contains 3900 records
- Features include:
  - Age
  - Gender
  - Category
  - Purchase Amount (USD)
  - Review Rating

## 🔍 Analysis Performed

### 1. Exploratory Data Analysis (EDA)
- Purchase distribution using histogram
- Category-wise sales using bar chart
- Age-wise spending analysis

### 2. SQL Analysis
- Category-wise total sales
- Age-wise spending insights
- Aggregation and grouping queries

### 3. Dashboard
- Combined visual dashboard
- Pie chart for category distribution
- Graphs showing key insights

## 📈 Key Insights
- Clothing category has highest sales
- Outerwear has lowest sales
- Customers aged 40–70 spend more
- Spending distribution is consistent

## 🛠 Tools Used
- Python (Pandas, Matplotlib)
- SQL (SQLite)
- Google Colab
- GitHub

## 📌 Conclusion
This analysis helps understand customer behavior and provides valuable insights for business decision-making.
